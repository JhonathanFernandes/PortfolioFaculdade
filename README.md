# Portfólio Acadêmico — Jhonathan Fernandes

Portfólio desenvolvido como projeto acadêmico para apresentar informações pessoais, formação, trajetória profissional e projetos na área de tecnologia.

## Conteúdo

- Apresentação pessoal.
- Seção sobre trajetória e transição para tecnologia.
- Formação acadêmica.
- Área de projetos.
- Informações de contato.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/JhonathanFernandes/PortfolioFaculdade.git
   ```
2. Entre na pasta:
   ```bash
   cd PortfolioFaculdade
   ```
3. Abra o arquivo `index.html` no navegador.

O projeto utiliza arquivos estáticos; não requer instalação de dependências para visualização básica.

## Objetivo

Praticar estruturação semântica com HTML, estilização com CSS, navegação por seções e apresentação de conteúdo em uma página web.
